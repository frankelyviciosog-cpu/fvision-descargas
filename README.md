# Fvision: instaladores

Fvision convierte las estadísticas de baloncesto en gráficos para la transmisión (vMix). Aquí están
sus instaladores para Windows 10 y 11.

## Descargar

**[Descargar la última versión](https://github.com/frankelyviciosog-cpu/fvision-descargas/releases/latest)**:
en esa página, toca el archivo `FvisionSetup-X.Y.Z.exe` (el número es la versión).

## Instalar

1. Abre el archivo descargado.
2. Si Windows dice *"Windows protegió tu PC"*, toca **Más información** y después **Ejecutar de todas
   formas** (el programa no tiene firma digital).
3. **Siguiente** → **Instalar** → **Finalizar**. No pide permisos de administrador.
4. Queda **Fvision** en el menú Inicio y en el escritorio.

Las versiones anteriores están en [Releases](https://github.com/frankelyviciosog-cpu/fvision-descargas/releases).
